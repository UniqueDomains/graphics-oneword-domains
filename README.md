## 🧱 Field summary

- `domain` — Fully qualified domain name.
- `status` — Current acquisition state for the domain in the public extract.
- `purchase_price` — Visible purchase price when available.
- `renewal_price` — Visible renewal price when available.
- `attractiveness` — Composite naming score used as a decision-support signal.
- `demand` — Relative buyer-pressure score when available.
- `length` — Character count without the TLD.
- `registrar` — Registrar name when known.
- `created_at` — Creation timestamp when known.
- `expires_at` — Expiry timestamp when known.

## ⚠️ Methodology and caveats

This selection is entirely made up of one-word .graphics domains. The names span broad dictionary-style terms and short brandable words, from tips.graphics and homes.graphics to Trex.graphics and finals.graphics. With 12,181 domains in the set and a median ask of 32.95, the main question is not scarcity but fit. Founders should focus on whether the word is easy to remember, relevant to a visual or design-led brand, and credible on a niche extension. Investors should weigh entry price against the narrower buyer pool that a .graphics name usually implies. When comparing these domains, keep renewal burden, trademark sensitivity, and category clarity in view.
